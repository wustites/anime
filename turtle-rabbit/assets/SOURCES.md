# Bundled dependencies

- `gsap.min.js`: GSAP 3.14.2, https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js.
  Copyright and license link are retained in the file header.
- `story-regular.woff2`: Noto Serif SC Regular, subset from
  https://fonts.gstatic.com/s/notoserifsc/v35/H4cyBXePl9DZ0Xe7gG9cyOj7uK2-n-D2rd4FY7SCqyWv.ttf.
- `story.woff2`: Noto Serif SC Black, subset from
  https://fonts.gstatic.com/s/notoserifsc/v35/H4cyBXePl9DZ0Xe7gG9cyOj7uK2-n-D2rd4FY7QrrCWv.ttf.
- `FONT-LICENSE.txt`: Noto SIL Open Font License,
  https://github.com/notofonts/noto-cjk/blob/main/Serif/LICENSE.

Runtime fonts and animation code are local. No media is fetched during rendering.
