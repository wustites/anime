# 龟兔赛跑 · 动态绘本

共用 `../crow-water/DESIGN.md` 的暖纸、细墨线和分层场景系统。
兔子的珊瑚色马甲与乌龟的灰绿龟壳提供角色辨识；围巾、耳朵和脚步
承担动作节奏，不用文字速度线代替角色表演。

保持 23 秒与原旁白时间：

1. 0–3.8 秒：森林赛道开赛；兔子与乌龟从同一场景出发。
2. 3.8–10.2 秒：兔子快速跑到树下，减速、靠坐、闭眼呼吸；乌龟继续慢走。
3. 10.2–17.5 秒：乌龟持续迈步接近终点；兔子醒来后加速追赶。
4. 17.5–23 秒：乌龟穿过终点，红色终点带收起；观众欢呼，兔子垂耳，保留完整场景呈现寓意。

步态用交替的前后脚、身体起伏、头部跟随组成。兔子步幅大、步频快，
乌龟步幅小、步频慢。开篇和寓意文字避开赛道；字幕保持与旁白同步。
共享源文件与生成命令见 `../storybook/README.md`。
